One pickup line a robot would use: a robot on 1% battery spends its last percent walking over to ask your name. `main.ts` writes it to `/output/entry.txt` for make.fun's The Robot Pickup Line Championship.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
